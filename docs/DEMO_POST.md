Do not post this. The human posts it.

A hackathon repo only gets one shot, and the first reader is a program that checks the README against the code.

DryRun runs that read before you submit. Paste a public repo, get the rule result, and open the NEAR testnet receipt that stores the repo, the commit, the result hash, the time, and the checker version. A priced deep review is a NEAR Intents 1Click quote with dry:true — nothing is deposited — and that quote is written into the same kind of receipt. The guessed board is labelled an estimate and hides other teams' names unless you ask to see them.
