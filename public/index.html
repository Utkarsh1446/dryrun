Reading the directory.

The rules are public. The field is public. The ranking is not.

On NEAR HACKATHON a submission cannot be edited after it is sent. A change goes through a request queue. The useful moment is before that send.

The screen asks whether the repository is public, whether it has a license, whether the README's commands exist, and whether secrets are sitting in the tree. __NAME__ runs that list. It does not execute the project, and it does not rewrite it.

The directory publishes a name, the tracks, and a demo post. It does not publish the repository. When a demo post or a GitHub search points at a public repo, the match is shown with a confidence. When it does not, the entry stays unscored.

How a reading is made

01Read the directory.

One page after another, with a pause between them. A snapshot is kept when the count changes.

02Match a repository.

A link in the project's own demo post is high confidence. A name search is lower, and it is labeled as a search.

03Score the rules.

Clone, read, delete. The same checks as the free pre-judge. Nothing in the repo is run.

04Place yourself.

Paste a repo. The rank is among the repositories that were actually scored, with the fixes in order.

Questions

Is the leaderboard the official result?

No. It is a reading of the published rules against the public repositories this process could match and score. Judges decide. The order will move as more repositories are scored.

Do you run the code in a repository?

No. A repository is cloned, read, and deleted. "Commands resolve" means the scripts and files named in the README exist. It does not mean they succeed. Symlinks are skipped. Secret values are not printed.

What does a match mean?

High confidence means the first GitHub link in that project's public demo post. That link can still be a dependency rather than the submission. Medium confidence means a GitHub name search cleared a conservative threshold, and it can be the wrong repository. Entries with no match are left unscored.

What if my repository is still private?

It cannot be scored, and the screeners cannot open it either. Make it public, then paste the link.

What does the deep review cost, and what if there is no API key?

The price on this page comes from the server configuration. Without NEAR_AI_API_KEY the free checks, the board, rank, and the idea check still run. The model is not called. A gateway signature, when the API returns one, is shown with the kind the API sends. It is not described as an enclave attestation.

Share is of entries that list the track. A project can list several. Room means under 12% of the directory. Crowded means 25% or more.

Name clusters

A cluster is a distinctive word shared by at least three names, and not so common that it describes the whole directory. Same-name groups ignore spaces and camel case.
